Overview
This C# console application was developed for COP2360 Group Project 1. It implements a custom Dictionary Management System using a Dictionary<string, List<string>> data structure, allowing users to store, manage, and sort multiple string values under distinct categorical keys.

Features
The program runs an interactive menu with the following capabilities:

1. Populate Dictionary: Clears existing data and loads the dictionary with default categories and values.

2. Display Dictionary: Iterates through and displays all current keys and their comma-separated values.

3. Remove a Key: Prompts the user to delete a specified key and its associated list of values.

4. Add a New Key and Value: Creates a new, unique key and assigns it an initial starting value.

5. Add a Value to an Existing Key: Appends a new string value to the list of an already established key.

6. Sort the Keys: Sorts and displays the dictionary's contents in alphabetical order by key.

7. Exit: Safely terminates the application loop.
